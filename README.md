# Emir Lab

**Любопытство, воплощённое в коде.**

Личный хаб проектов Эмира: приложения, игры, инженерные эксперименты и DevOps-инструменты в одной адаптивной bento-сетке.

**[Открыть сайт](https://project-lab-7kr8xl7je95.qoder.website)** · **[GitHub автора](https://github.com/remageht)**

## О проекте

Emir Lab помогает познакомиться с моими проектами и перейти к их исходникам, опубликованным веб-приложениям или готовым релизам. Вместо полного списка репозиториев здесь собрана небольшая подборка самостоятельных продуктов.

Хаб — отдельный статический сайт. Он не запускает перечисленные приложения внутри себя и не требует их установки для просмотра.

## Дизайн и возможности

- Графитовая палитра с тёплым оранжевым акцентом и карточками разных размеров.
- 3D-цикл «идея → сборка → повтор» в шапке: орбита с узлами, искра, стрелка повтора и спутник.
- Детализированные 3D-композиции в каждой основной карточке: микросхемы, устройства, микрофон, серверы, компас, планета и другие объекты по теме проекта.
- Металлические материалы, студийное освещение, объёмные детали и самостоятельное движение отдельных частей моделей.
- Один общий WebGL-рендерер для всех сцен; обновляется только видимая область, активно анимируется одна композиция за раз.
- Настоящие скриншоты Astro Voyager и MikroLab и исходные иллюстрации сохранены как запасной вариант без WebGL.
- Поэтапное появление шапки: строки заголовка выезжают из маски, акцентная линия прочерчивается под меню, остальные блоки всплывают по очереди.
- Слово «Воплощённое» материализуется по буквам: каждая загорается снизу вверх из пустого контура, а наведение на заголовок повторяет эффект.
- За курсором в шапке идёт мягкий блик по буквам, а текст и 3D-цикл слегка расходятся в противоположные стороны.
- Плавное появление карточек, подсветка под курсором и реакция 3D-объектов на наведение.
- Живой подвал: мини-искра в общем WebGL-рендерере, пульсирующий статус со сменой слоганов и акцентная линия, которая заполняется по мере прокрутки страницы.
- В блоке об авторе слово «создавать» собирается по буквам: каждая прилетает в палитре одного из проектов и лишь потом укладывается в общий тон — разные дела, одно занятие.
- Переключатель анимации и поддержка системной настройки `prefers-reduced-motion`.
- Адаптивная сетка для компьютеров и телефонов.
- Управление с клавиатуры, заметные состояния фокуса и ссылка для перехода к основному содержимому.
- Поддержка дизайн-настроек Qoder Sites через CSS-переменные: оформление, радиус, интервалы, типографика и движение.

## Технологии

**HTML5 · CSS3 · Vanilla JavaScript · Three.js · Node.js · Qoder Sites**

Единственная клиентская зависимость — **Three.js 0.187.0**. Библиотека поставляется вместе с сайтом, без загрузки с CDN. Модели создаются программно; внешний сервер моделей не нужен. Нет базы данных, API-ключей и обязательного бэкенда. Node.js используется для локального сервера, проверки синтаксиса и сборки статического сайта.

## Локальный запуск

Нужны **Node.js 22 или новее** и npm. Зависимости устанавливаются из зафиксированного `package-lock.json`.

```bash
git clone https://github.com/remageht/project-hub.git
cd project-hub
npm ci
npm run dev
```

Сервер выводит адрес и PID в терминал. По умолчанию сайт доступен на `http://127.0.0.1:4173/`.

## Проверка и сборка

```bash
npm run check
npm run build
```

- `npm run check` проверяет синтаксис JavaScript сайта и служебных скриптов.
- `npm run build` пересоздаёт `dist/` и копирует туда содержимое `web/`.
- Папка `dist/` содержит готовый статический сайт для публикации и не хранится в Git.

Синтаксическая проверка не заменяет проверку интерфейса в браузере. Перед первой публикацией были проверены основные переходы, анимация, управление с клавиатуры, мобильная и горизонтальная компоновки, а также увеличение текста до 200%.

## Структура

```text
project-hub/
├── README.md
├── package.json
├── scripts/
│   ├── serve.mjs       # Локальный сервер на 127.0.0.1:4173
│   ├── build.mjs       # Сборка статического сайта в dist/
│   └── vendor.mjs      # Подготовка локальных модулей Three.js
└── web/
    ├── index.html      # Тексты, карточки проектов и ссылки
    ├── style.css       # Дизайн, адаптивность и CSS-переменные
    ├── main.js         # Анимация, переключатель и текущий год
    ├── project-objects.js # Тематические 3D-модели и общий рендерер
    ├── vendor/         # Модули Three.js, создаются при запуске и сборке
    └── assets/         # Оптимизированные изображения и favicon
```

Для добавления проекта измените карточки в [`web/index.html`](web/index.html). Оформление находится в [`web/style.css`](web/style.css), общее поведение — в [`web/main.js`](web/main.js), а модели и их анимация — в [`web/project-objects.js`](web/project-objects.js).

## Публикация

Текущая версия опубликована на **Qoder Sites** с открытым доступом. Готовую папку `dist/` также можно разместить на другом хостинге статических сайтов; сервер Node.js для опубликованной версии не нужен.

Для обновления на Qoder Sites используются исходный локальный проект и его существующая привязка сайта. Служебные файлы `*.qoder.site` и `.qoder/` не включаются в репозиторий.
