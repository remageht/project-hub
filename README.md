# Emir Lab

**Любопытство, воплощённое в коде.**

Личный хаб проектов Эмира: приложения, игры, инженерные эксперименты и DevOps-инструменты в одной адаптивной bento-сетке.

**[Открыть сайт](https://project-lab-7kr8xl7je95.qoder.website)** · **[GitHub автора](https://github.com/remageht)**

## О проекте

Emir Lab помогает познакомиться с моими проектами и перейти к их исходникам, опубликованным веб-приложениям или готовым релизам. Вместо полного списка репозиториев здесь собрана небольшая подборка самостоятельных продуктов.

Хаб — отдельный статический сайт. Он не запускает перечисленные приложения внутри себя и не требует их установки для просмотра.

## Дизайн и возможности

- Графитовая палитра с тёплым оранжевым акцентом и карточками разных размеров.
- Настоящие скриншоты Astro Voyager и MikroLab, а также иконка из репозитория HushDrop.
- Плавное появление карточек, подсветка под курсором и тематические реакции на наведение.
- Переключатель анимации и поддержка системной настройки `prefers-reduced-motion`.
- Адаптивная сетка для компьютеров и телефонов.
- Управление с клавиатуры, заметные состояния фокуса и ссылка для перехода к основному содержимому.
- Поддержка дизайн-настроек Qoder Sites через CSS-переменные: оформление, радиус, интервалы, типографика и движение.

## Технологии

**HTML5 · CSS3 · Vanilla JavaScript · Node.js · Qoder Sites**

У сайта нет сторонних runtime-зависимостей, базы данных, API-ключей и обязательного бэкенда. Node.js используется только для локального сервера, проверки синтаксиса и копирования статического сайта в папку публикации.

## Локальный запуск

Нужны **Node.js 22 или новее** и npm. Устанавливать пакеты не требуется.

```bash
git clone https://github.com/remageht/project-hub.git
cd project-hub
npm run dev
```

Сервер выводит адрес и PID в терминал. По умолчанию сайт доступен на `http://127.0.0.1:4173/`.

## Проверка и сборка

```bash
npm run check
npm run build
```

- `npm run check` проверяет синтаксис JavaScript сайта и служебных скриптов.
- `npm run build` пересоздаёт `dist/` и копирует туда содержимое `web/`.
- Папка `dist/` содержит готовый статический сайт для публикации и не хранится в Git.

Синтаксическая проверка не заменяет проверку интерфейса в браузере. Перед первой публикацией были проверены основные переходы, анимация, управление с клавиатуры, мобильная и горизонтальная компоновки, а также увеличение текста до 200%.

## Структура

```text
project-hub/
├── README.md
├── package.json
├── scripts/
│   ├── serve.mjs       # Локальный сервер на 127.0.0.1:4173
│   └── build.mjs       # Сборка статического сайта в dist/
└── web/
    ├── index.html      # Тексты, карточки проектов и ссылки
    ├── style.css       # Дизайн, адаптивность и CSS-переменные
    ├── main.js         # Анимация, переключатель и текущий год
    └── assets/         # Оптимизированные изображения и favicon
```

Для добавления проекта измените карточки в [`web/index.html`](web/index.html). Оформление находится в [`web/style.css`](web/style.css), поведение — в [`web/main.js`](web/main.js).

## Публикация

Текущая версия опубликована на **Qoder Sites** с открытым доступом. Готовую папку `dist/` также можно разместить на другом хостинге статических сайтов; сервер Node.js для опубликованной версии не нужен.

Для обновления на Qoder Sites используются исходный локальный проект и его существующая привязка сайта. Служебные файлы `*.qoder.site` и `.qoder/` не включаются в репозиторий.
